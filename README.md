# Tax Services Landing Page

**A service-business website demonstrating frontend layout, service presentation, mobile navigation, and interactive FAQs.**

[View the website](https://ahsaan-tax.vercel.app)

## What it demonstrates

- A long-form landing page organized around services, process, sample work, FAQs, and contact.
- HTML and CSS layouts with mobile navigation.
- JavaScript accordion interactions, scroll effects, and animated headline text.
- Detailed document-style visual mockups in the sample-work section.
- A static deployment configuration for Vercel.

This repository is a frontend example. It does not contain a tax-processing backend or a contact-submission service. Business credentials, testimonials, and savings claims in the page copy are not verified by the code repository.

## Run locally

```bash
git clone https://github.com/ahsaan-10/Ahsaan_Tax_Site.git
cd Ahsaan_Tax_Site
python -m http.server 8080
```

Open `http://localhost:8080`. No package installation or build step is required; external fonts need network access.

## Repository map

```text
index.html    Page content, styles, and browser interactions

```

Review the service sections, open an FAQ, and inspect the navigation at a narrow viewport. Present the contact section as an interface unless a working submission service has been configured separately.
